# Set up a new virtual machine

## Open Olacle Virtualbox
- Select it from desktop or start manual
- Click it and make sure it load correctly
## Click Create a new virtual machine (VM)
- Click New in the top toolbar
- Enter a name for the VM 
## Select an iso file
- Click ISO Image or Browse
- Make sure correct OS is detected
## Set all parameters of this virtual machine
- Set RAM
- Set CPU cores
- Set HDD
## Click save
- You can test run
