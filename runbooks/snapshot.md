# Take snapshot

## Pre snapshot check
- Make sure the VM is running
- Makesure the VM is running normally and in the state that intent to take snapshot

## Take snapshot
- Click "Machine" and "Snapshot"
- Enter name of snapshot and click "save"
- Wait the snapshot done

# Restore from a snapshot

## Pre restore check
- Make sure VM is not running
- The "restore" button will be grey if VM is still running

## Restore
- In "snapshot" tag select snapshot intent to restore
- Click "restore" and "yes"
- Wait the VM on and restore dones
