# Testing windows BSOD(Blue Scrren of Death) with notmyfault
https://www.youtube.com/shorts/GA4B_FxLEww

## Move the notmyfault to virtual machine
- Download notmyfault from Microsoft website
- Make an iso file with notmyfault.zip
- Mount it to virtual machine

## Run the test in virtual machine
- Release the nomyfault file in VM
- Run terminal in admin and navigate to the folder
- Run command ./notmyfaultc64.exe /(option) in terminal
